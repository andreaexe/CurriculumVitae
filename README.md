# Curriculum Vitae - Andrea Sestini

Repository contenente il mio curriculum vitae in formato web, con focus sulle competenze in ambito Cybersecurity.

## Descrizione

Questo repository contiene il codice sorgente del mio CV digitale, strutturato in HTML e CSS. Il curriculum presenta le mie competenze tecniche, formazione, certificazioni e informazioni personali in un formato responsive e facilmente accessibile.

## Tecnologie utilizzate

- HTML5
- CSS3
- Font Awesome per le icone
- Google Fonts

## Visualizza il CV online

Puoi visualizzare il mio curriculum online al seguente indirizzo:

## Struttura del progetto

- `cv.html` - File principale contenente la struttura del CV
- `style.css` - Stili di formattazione del CV
- `fotoAttuale.png` - Foto profilo
